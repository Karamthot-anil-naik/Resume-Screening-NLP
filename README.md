# 📄 Resume Screening using NLP

An AI-powered Applicant Tracking System (ATS) built with **Python, NLP, Machine Learning, and Streamlit**. This application analyzes resumes against job descriptions, calculates ATS match scores, identifies matching and missing skills, and generates an ATS report.

---

## 🚀 Live Demo


https://resume-screening-nlp-8xw8xu67rkj2bttdy55yjf.streamlit.app/
---

## 📌 Features

- Upload Resume (PDF)
- Paste Job Description
- Automatic Resume Parsing
- NLP-based Text Cleaning
- TF-IDF Vectorization
- Cosine Similarity Matching
- ATS Match Score
- Skills Extraction
- Missing Skills Detection
- Interactive Dashboard
- Download ATS Report

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Resume-Screening-NLP.git
```

Move inside the folder

```bash
cd Resume-Screening-NLP
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
